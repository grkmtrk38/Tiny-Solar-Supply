# Tiny Solar Supply ☀️🔋

This project is a compact solar power supply module, originally inspired by and based on the design featured in [Elektor Magazine](https://www.elektormagazine.com/magazine/elektor-305/62009). It is designed to harvest solar energy efficiently for low-power embedded systems, sensor nodes, and IoT devices.

## ✨ Features
* **Solar Energy Harvesting:** Optimized for small solar panels to provide stable continuous power.
* **Power Management:** Integrated circuitry for safe voltage regulation and energy storage charging.
* **Low Quiescent Current:** Designed to minimize power loss during operation.
* **Compact Footprint:** Minimalist PCB design suitable for space-constrained DIY projects.

## 📂 Repository Structure
* `/Gerber` - Manufacturing files (Gerbers and Drill files) ready for production.
* `tiny solar supply.pdf` - High-resolution schematic file.
* `tiny solar supply.kicad_pro` - KiCad 8.0 project workspace.

## 🛠️ Built With
* **[KiCad](https://www.kicad.org/)** - Open-source PCB design software.

## 🏭 Manufacturing
The fabrication files are located in the `Gerber` directory. You can directly compress this folder into a `.zip` file and upload it to your preferred PCB manufacturer (such as JLCPCB or PCBWay). 

**Board Specifications:**
* Layers: 2
* Copper Thickness: 1 oz
* Board Thickness: 1.6 mm
